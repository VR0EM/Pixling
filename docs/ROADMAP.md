# Roadmap

Platform order: macOS first, then Windows, then Linux.

## Phase 1: It's alive

- [x] Transparent window above everything, over the work area of the main screen
- [x] Clicks go through the window, except on the buddy
- [x] Six buddies, eight colours, five accessories, three sizes
- [x] Walking, breathing, blinking, looking at the cursor
- [x] Sleeping after a minute without mouse movement, waking up on movement
- [x] Dragging, throwing with gravity and bouncing, petting with a click
- [x] Menu bar icon with a menu, settings saved in a JSON file
- [x] Fitting again when the Dock or the main screen changes
- [x] Right-clicking the buddy opens the same menu as the menu bar
- [x] After a click, the app you were working in gets the focus back
- [x] Start at login (option in the menu)
- [x] No focus change at all on a click (macOS: non-activating panel)
- [ ] Several screens: moving along and throwing between screens
- [x] Fading into the background during video calls in your calendar
- [ ] Hiding for fullscreen apps and video calls that aren't in the calendar

## Phase 2: It watches along

- [x] Sitting on the top edge of windows, riding along when you drag the window, falling off when it closes or you yank it (macOS)
- [x] Jumping onto windows by itself, and off again
- [x] Reacting to the app in front: laptop for code, headphones (or a boombox) for music, popcorn for video, controller for games
- [x] Sitting still while you code
- [ ] Recognising music playing in the background, not only when the music app is in front
- [x] Window list and the app in front on Windows
- [ ] Window list and the app in front on Linux
- [x] Time of day and special days: coffee, nightcap, Friday evening, New Year's Eve, winter
- [x] Your birthday, the day you met and every hundred days: cake and confetti
- [x] Weather: umbrella, beanie, sunglasses, rain and snow
- [x] Holidays: Halloween, Christmas, snow on the windows, an Easter egg hunt
- [ ] Typing tempo (only the tempo, never the keys)
- [x] Speech bubbles in a pixel font (Pixelify Sans)

## Phase 3: It helps

- [x] Backpack in the menu, with reminders you switch on and off
- [x] Focus timer: it reads along, the time shows next to the menu bar icon, then a break
- [x] Reminders: water, and getting tired after an hour without a break
- [x] Calendar (Google, iCloud, Outlook through their iCal address): today's plan, heads-up before meetings, quiet in meetings, fading away in video calls, birthdays
- [ ] Your own calendar from the computer (macOS Calendar, Windows Calendar) without an address
- [x] Quick note: type, Enter, done
- [x] Feeding it files: zip, convert an image, copy the path, show in Finder
- [x] System: low battery, plugged in, busy computer
- [ ] Notes as a reminder at a set time

## Phase 4: It's yours

- [x] Wardrobe window with a preview
- [x] Studio: pixel editor for your own accessories (hat, face, to hold)
- [x] Drawing your own buddies, in layers, with your own colours
- [x] Sharing and adding creations as `.pixling.json` files, also by dropping them on the buddy
- [x] A prompt and a guide so AI assistants can make buddies
- [x] Character: calm, hyper, cheeky or sweet
- [x] Every built-in buddy its own voice and quirk: the robot charges, the mug gets refilled, the dragon flies, the ghost vanishes, the sprout grows, the shroom bounces and glows
- [ ] Writing your own phrases
- [ ] Rules: "if … then …"
- [x] Diary and "buddies for … days"
- [x] Games: fetch, hide and seek, basket
- [x] Sticker book with accessories to earn (or unlock everything)
- [ ] Two buddies at once, waving and playing tag
- [ ] Music in the background, not only when the music app is in front

## Later

- [ ] An AI brain so you can really chat with it
- [ ] Sending your buddy to visit a friend

## Windows and Linux

- [x] Windows: window list, app in front, dragging files, file actions, battery and load, tray icon, no focus stealing
- [x] Downloads: a .dmg and Windows .exe files built by GitHub for every release
- [ ] Windows: try it on a real PC (transparency, letting clicks through, the tray, DPI scaling, several screens)
- [ ] Linux: test X11 and Wayland; letting clicks through doesn't work the same everywhere
