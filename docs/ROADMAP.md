# Roadmap

Volgorde van platformen: eerst macOS, dan Windows, dan Linux.

## Fase 1: Hij leeft

- [x] Doorzichtig venster boven alles, over het werkgebied van het hoofdscherm
- [x] Klikken gaan door het venster, behalve op het maatje
- [x] Zes maatjes, zeven kleuren, vier accessoires, drie groottes
- [x] Rondlopen, ademen, knipperen, naar de cursor kijken
- [x] Slapen na een minuut zonder muisbeweging, wakker worden bij beweging
- [x] Slepen, gooien met zwaartekracht en stuiteren, aaien met een klik
- [x] Menubalkicoon met keuzemenu, instellingen bewaard in een JSON-bestand
- [x] Opnieuw passend maken als het Dock of het hoofdscherm verandert
- [x] Rechtsklik op het maatje opent hetzelfde menu als de menubalk
- [ ] Klikken op het maatje zonder dat de app waar je in werkt de focus verliest (macOS: niet-activerend paneel)
- [ ] Meerdere schermen: meeverhuizen en tussen schermen gooien
- [ ] Verstoppen bij fullscreen-apps en videocalls
- [ ] Starten bij het inloggen (optie in het menu)

## Fase 2: Hij kijkt mee

- [ ] Op de titelbalk van vensters zitten en meerijden als je het venster sleept (macOS: vensterlijst via CoreGraphics)
- [ ] Reageren op de actieve app: brilletje bij code, koptelefoon bij muziek, popcorn bij video
- [ ] Tijd van de dag en speciale dagen: koffie, slaapmuts, vrijdagmiddag, verjaardag, Sinterklaas
- [ ] Typtempo (alleen het tempo, nooit de toetsen)
- [ ] Tekstballonnen met een eigen pixel-lettertype

## Fase 3: Hij helpt

- [ ] Rugzak met modules die je aan en uit zet
- [ ] Focustimer: hij leest mee en rekt zich uit bij de pauze
- [ ] Herinneringen: water, pauze, volgende afspraak
- [ ] Snelle notitie: klik, typ, klaar
- [ ] Bestanden voeren: zippen, afbeelding omzetten, pad kopiëren
- [ ] Systeem: lege batterij, zwoegende computer

## Fase 4: Hij is van jou

- [ ] Kleerkast-venster met voorbeeld
- [ ] Pixeleditor voor eigen accessoires, en eigen maatjes inladen
- [ ] Karakter: rustig, druk, brutaal of lief; zelf zinnetjes schrijven
- [ ] Regels: "als … dan …"
- [ ] Dagboek en "al zo lang maatjes"

## Later

- [ ] Een AI-brein zodat je echt met hem kan kletsen
- [ ] Je maatje op bezoek sturen bij een vriend

## Windows en Linux

- [ ] Windows: doorzichtigheid, klikken doorlaten en systeemvak testen; het werkgebied zonder taakbalk gebruiken
- [ ] Linux: X11 en Wayland testen; klikken doorlaten werkt niet overal hetzelfde
