# Roadmap

Volgorde van platformen: eerst macOS, dan Windows, dan Linux.

## Fase 1: Hij leeft

- [x] Doorzichtig venster boven alles, over het werkgebied van het hoofdscherm
- [x] Klikken gaan door het venster, behalve op het maatje
- [x] Zes maatjes, zeven kleuren, vier accessoires, drie groottes
- [x] Rondlopen, ademen, knipperen, naar de cursor kijken
- [x] Slapen na een minuut zonder muisbeweging, wakker worden bij beweging
- [x] Slepen, gooien met zwaartekracht en stuiteren, aaien met een klik
- [x] Menubalkicoon met keuzemenu, instellingen bewaard in een JSON-bestand
- [x] Opnieuw passend maken als het Dock of het hoofdscherm verandert
- [x] Rechtsklik op het maatje opent hetzelfde menu als de menubalk
- [x] Na een klik krijgt de app waar je in werkte de focus terug
- [x] Starten bij het inloggen (optie in het menu)
- [ ] Helemaal geen focuswissel bij een klik (macOS: niet-activerend paneel)
- [ ] Meerdere schermen: meeverhuizen en tussen schermen gooien
- [ ] Verstoppen bij fullscreen-apps en videocalls

## Fase 2: Hij kijkt mee

- [x] Op de bovenrand van vensters zitten, meerijden als je het venster sleept, eraf vallen als het sluit of je eraan rukt (macOS)
- [x] Zelf op vensters springen, en eraf springen
- [x] Reageren op de actieve app: leesbril bij code, koptelefoon bij muziek, popcorn bij video, controller bij games
- [ ] Muziek herkennen die op de achtergrond speelt, niet alleen als de muziekapp vooraan staat
- [ ] Vensters en actieve app op Windows en Linux
- [x] Tijd van de dag en speciale dagen: koffie, slaapmuts, vrijdagavond, oudejaarsavond, Sinterklaas
- [ ] Je verjaardag (vraagt een datum in de kleerkast)
- [ ] Typtempo (alleen het tempo, nooit de toetsen)
- [ ] Tekstballonnen met een eigen pixel-lettertype

## Fase 3: Hij helpt

- [x] Rugzak in het menu, met herinneringen die je aan en uit zet
- [x] Focustimer: hij leest mee, de tijd staat naast het menubalkicoon, daarna een pauze
- [x] Herinneringen: water, en moe worden na een uur zonder pauze
- [ ] Herinnering voor je volgende afspraak (agenda)
- [x] Snelle notitie: typ, Enter, klaar
- [x] Bestanden voeren: zippen, afbeelding omzetten, pad kopiëren, tonen in Finder
- [x] Systeem: bijna lege batterij, stekker erin, zwoegende computer
- [ ] Notities als herinnering op een tijdstip

## Fase 4: Hij is van jou

- [x] Kleerkast-venster met voorbeeld
- [ ] Pixeleditor voor eigen accessoires, en eigen maatjes inladen
- [ ] Karakter: rustig, druk, brutaal of lief; zelf zinnetjes schrijven
- [ ] Regels: "als … dan …"
- [ ] Dagboek en "al zo lang maatjes"

## Later

- [ ] Een AI-brein zodat je echt met hem kan kletsen
- [ ] Je maatje op bezoek sturen bij een vriend

## Windows en Linux

- [ ] Windows: doorzichtigheid, klikken doorlaten en systeemvak testen; het werkgebied zonder taakbalk gebruiken
- [ ] Linux: X11 en Wayland testen; klikken doorlaten werkt niet overal hetzelfde
